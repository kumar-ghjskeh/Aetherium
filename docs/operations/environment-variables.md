# Environment Variables

`.env.example` lists variable names only. Real values belong in local `.env` files or deployment
secret managers.

## Core

- `AETHERIUM_APP_ENV`: `development`, `test`, `staging`, or `production`.
- `AETHERIUM_DATABASE_URL`: async SQLAlchemy PostgreSQL URL for the environment.
- `AETHERIUM_REDIS_URL`: environment-specific Redis URL.
- `AETHERIUM_REDIS_KEY_PREFIX`: must start with `aetherium:`.
- `AETHERIUM_CORS_ORIGINS`: comma-separated frontend origins. Never use `*` with credentials.
- `NEXT_PUBLIC_AETHERIUM_API_BASE_URL`: browser-visible API base URL for the matching environment.

## Object Storage

- `AETHERIUM_OBJECT_STORAGE_ENDPOINT`
- `AETHERIUM_OBJECT_STORAGE_BUCKET`
- `AETHERIUM_OBJECT_STORAGE_DERIVED_ASSETS_BUCKET`
- `AETHERIUM_OBJECT_STORAGE_USER_AVATARS_BUCKET`
- `AETHERIUM_S3_ACCESS_KEY_ID`
- `AETHERIUM_S3_SECRET_ACCESS_KEY`
- `AETHERIUM_S3_REGION`

Production buckets must be private, Aetherium-prefixed, and separate from staging/development.

- `AETHERIUM_SESSION_COOKIE_PATH`
- `AETHERIUM_SESSION_COOKIE_SAMESITE`

- `AETHERIUM_ARGON2_TIME_COST`

## Observability And Backups

- `AETHERIUM_LOG_NAMESPACE`
- `AETHERIUM_REQUEST_ID_HEADER`
- `AETHERIUM_SECURITY_HEADERS_ENABLED`
- `AETHERIUM_CONTENT_SECURITY_POLICY`
- `AETHERIUM_METRICS_ENABLED`
- `AETHERIUM_ERROR_TRACKING_DSN`
- `AETHERIUM_BACKUP_BUCKET`

Do not log or expose error-tracking DSNs, backup credentials, provider keys, session secrets,
cookies, raw prompts, private file contents, object keys, or authentication material.
