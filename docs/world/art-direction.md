# Art Direction

## Direction

Aetherium World Mode uses stylized cinematic realism: physically plausible lighting, readable
materials, elegant silhouettes, and natural landscapes with a restrained fantasy-futuristic
language.

The world should feel calm, premium, and focused for study. It should avoid photorealistic human
uncanniness, heavy neon clutter, and imitation of copyrighted game maps or brands.

## Design Memory

The memorable image should be a quiet mountain-ring campus at dusk: a luminous Aetherium crystal
above a circular plaza, water flowing through learning districts, and distinct landmarks visible
from long paths.

## Palette

| Token     | Meaning                | Use                                       |
| --------- | ---------------------- | ----------------------------------------- |
| Violet    | Aetherium energy       | Core crystal, world paths, active prompts |
| Blue      | Knowledge and learning | Library, academy, learning panels         |
| Cyan      | Coding and systems     | Coding Arena, terminals, diagnostics      |
| Green     | Habits and growth      | Habit Garden, nature feedback             |
| Gold      | Achievements           | Achievement Hall, milestone accents       |
| Orange    | Projects and creation  | Project Dock, construction states         |
| White     | Neutral information    | Labels, system UI, readable highlights    |
| Deep navy | Interface base         | HUD, overlays, Command Mode bridge        |

Use color as identity, not noise. Status must never be communicated by color alone.

## Materials

Primary materials:

- Weathered stone.
- Frosted and clear glass.
- Brushed dark metal.
- Crystal.
- Wet rock.
- Moss and grass.
- Polished wood in sanctuary and study areas.
- Low-opacity holographic panels.

Energy channels should be subtle, thin, and directional. Bloom is allowed only as a controlled
accent.

## Architecture Language

Buildings use:

- Tall vertical forms.
- Arches.
- Domes.
- Water integration.
- Bridges.
- Terraces.
- Sparing floating elements.
- Crystal cores or conduits.

Each district must have a silhouette that is recognizable from the central plaza.

## Character Direction

Use a stylized humanoid with:

- Dark cloak or long coat.
- Violet Aetherium emblem.
- Masked or abstract face.
- Simple readable proportions.
- Minimal accessories.

Locomotion quality matters more than face detail.

## UI Direction

World UI uses:

- Dark translucent panels.
- Crisp text.
- Spatial labels with distance-aware sizing.
- Minimal HUD.
- Context prompts near the interaction focus.
- Full 2D panels for reading, coding, AI chat, analytics, and settings.

Avoid cards inside cards and oversized marketing-style hero layouts inside the application shell.

## Motion Direction

Motion should be smooth and quiet:

- Slow water movement.
- Gentle foliage sway.
- Ambient particles only where meaningful.
- Camera travel with clear skip controls.
- No camera shake by default for study workflows.
- Reduced-motion mode disables cinematics, particles, and nonessential motion.
