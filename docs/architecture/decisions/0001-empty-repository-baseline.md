# ADR 0001: Establish Phase 0 Baseline In An Empty Repository

## Status

Accepted

## Context

The requested work depends on reading `AGENTS.md` and Phase 0 architecture documents. The workspace
started empty and was not a git repository, so those documents did not exist.

## Decision

Create the missing Phase 0 baseline documents before implementing the limited Phase 1 scaffold.

## Consequences

- The project now has explicit product, architecture, security, testing, and roadmap guidance.
- The scaffold can proceed without inventing hidden architecture.
- These documents are intentionally concise and must be expanded as later slices add real behavior.
